# Skill: Create Catalog UI

## Instrucciones

Crea una interfaz con:

- landing inicial;
- listado de productos;
- tarjetas de producto;
- filtro por categoría;
- búsqueda por texto;
- ficha de producto;
- estados de carga/error;
- diseño responsive.

## Reglas

- No hardcodees URLs de producción.
- Usa variables de entorno para API.
- Mantén accesibilidad básica.
- Añade tests si el stack lo permite.
