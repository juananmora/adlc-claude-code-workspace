# Skill: Review PR

## Instrucciones

Produce:

- resumen de cambios;
- relación con la spec;
- criterios cumplidos;
- criterios pendientes;
- evidencia de tests;
- findings de seguridad;
- riesgos;
- recomendación: aprobar, pedir cambios o bloquear.

## Reglas

- No apruebes sin evidencia.
- Señala incertidumbre.
- No ocultes riesgos.
