# Skill: Plan Agentic Work

Genera un plan de ejecución ADLC.

## Instrucciones

Incluye:

- capacidades necesarias;
- agentes seleccionados;
- skills por agente;
- tareas por fase;
- dependencias;
- artefactos esperados;
- validaciones automáticas;
- criterios de aceptación;
- puntos de aprobación humana;
- condiciones de escalado;
- bucles de corrección.

## Formato recomendado

Usa tablas Markdown para agentes y tareas. Usa listas de checks para gates.
