# Skill: Generate Tests

## Instrucciones

Deriva pruebas desde la spec.

Incluye:

- unit tests;
- integration tests;
- API tests;
- E2E tests;
- smoke tests;
- pruebas negativas;
- datos de prueba.

## Reglas

- Cada test debe tener propósito claro.
- No elimines tests fallidos para pasar pipeline.
- Reporta gaps de cobertura.
