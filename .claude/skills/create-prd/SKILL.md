# Skill: Create PRD

Crea una especificación breve, verificable y accionable.

## Instrucciones

Produce un documento con estas secciones:

1. Objetivo.
2. Alcance.
3. Fuera de alcance.
4. Usuarios o actores.
5. Requisitos funcionales.
6. Requisitos no funcionales.
7. Restricciones.
8. Arquitectura esperada.
9. Criterios de aceptación verificables.
10. Riesgos.
11. Puntos de aprobación humana.

## Reglas

- Escribe criterios de aceptación comprobables.
- Marca supuestos explícitamente.
- No inventes decisiones críticas si faltan datos; propón opciones.
- Mantén la spec como fuente de verdad.
